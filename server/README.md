# Размещение FORCE DROP ZONE на российском VPS

Эта ветка содержит весь сайт и сервер для двух форм: бронирование клуба и заявка на франшизу. Публичные страницы и `/api/*` обслуживаются с одного домена `club.forcezon.ru`. GitHub Pages и Sites после переноса не нужны.

Для запуска нужны: VPS в России с Node.js 20 или новее, SSH-доступ, доступ к DNS `forcezon.ru`, Caddy или другой HTTPS-прокси, токены Telegram-ботов и ID закрытых чатов для двух типов заявок.

1. Клонировать ветку `rf-hosting` на VPS. Сайт запускается без установки npm-зависимостей командой `node server/app.mjs` из корня репозитория.
2. Задать переменные из `server/.env.example` через менеджер сервисов. Секреты не класть в Git или в HTML/JS. `PUBLIC_ORIGIN` должен быть `https://club.forcezon.ru`.
3. Запустить сервер как постоянный сервис от непривилегированного пользователя. Он слушает только `127.0.0.1:3000`; наружу должен смотреть HTTPS-прокси. Пример Caddy — `server/Caddyfile.example`.
4. Проверить `https://club.forcezon.ru/healthz`, обе страницы и отправку помеченных тестовых заявок.
5. Только после этого заменить DNS-запись `club.forcezon.ru`, которая сейчас направляет сайт на GitHub Pages, на адрес российского VPS. После переключения проверить сайт из сети РФ без VPN.

Старый токен бота бронирования был опубликован в клиентском `script.js` и в истории Git. Его необходимо отозвать через BotFather и выдать новый. В этой ветке токена в публичном коде больше нет. Бронирование и франшиза могут использовать разных ботов: для каждого есть свои токен и chat ID.

Не переключать DNS до настройки нового токена и проверки обеих форм: текущая опубликованная версия сайта остаётся рабочей до завершения миграции.
